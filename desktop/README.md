# Wasipy Desktop (Windows x64)

The Wasipy desktop app for Windows 10/11 (64-bit), built with Electron.

## What it is

A desktop shell around the live Wasipy web app (https://wasipy.vercel.app).
The app itself is always up to date — when the website changes, the desktop
app changes too, with no reinstall. The shell adds:

- **System tray** — closing the window hides Wasipy in the tray; it keeps
  running and you can reopen it with one click.
- **Native reminder notifications** — due reminders pop up as Windows
  notifications, even when the window is closed (as long as the app runs).
- **Auto-start** — Wasipy starts with Windows (turn off in
  Windows Settings > Apps > Startup).
- **Offline page** — a friendly retry screen when there is no internet.
- **External links** open in your default browser.
- **Google sign-in opens in your default browser (Chrome)** — signing in or
  connecting a service never happens inside the app window. The app listens
  on a loopback address (`http://127.0.0.1:8765/auth/callback`) for
  Google's redirect back, then finishes the sign-in with the server
  (`/api/auth/desktop/*`) and saves the session in the app. That loopback
  address must be registered as an Authorized redirect URI on the Wasipy
  OAuth client in Google Cloud (the port must match exactly — Web clients
  match the redirect URI including the port).

## Download

Every push to `main` that touches `desktop/` builds the installer
automatically (GitHub Actions, Windows runner). Get it here:

**https://github.com/xparrowdev/wasipy/releases/tag/desktop-latest**

Download `Wasipy-Setup-*-x64.exe`, run it, sign in with Google once —
done. Your reminders and Google connections are the same as on the website.

## Run it locally (for development)

```bash
cd desktop
npm install
npm start
```

## Build the installer locally (Windows only)

```bash
cd desktop
npm install
npm run dist
```

The installer appears in `desktop/dist/`.

## Icons

`build/icon.png`, `build/icon.ico` and `build/tray.png` are generated by
`build/make-icon.py` (needs Pillow: `pip install pillow`). The GitHub Actions
build runs this automatically. For local runs, generate them once first:

```bash
cd desktop/build
python make-icon.py
```
